# Duncan TV Story Archive

Instagram story archiver for Duncan TV.

## Commands

- `npm run login` — open Instagram login flow using the persistent profile
- `npm run run` — archive current stories to `D:\projects\duncan-tv\media\stories`

## Local files kept out of git

- `.env`
- `ig-profile/`
- `runs/`
- `node_modules/`

## Env

Copy `.env.example` to `.env` and adjust if needed.
